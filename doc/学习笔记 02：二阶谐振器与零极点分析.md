## 一、二阶谐振器：本文的分析对象

研究"极点位置如何影响频响"，用一个最小、最干净的系统就够了 —— **二阶谐振器**（Second-order Resonator）：

$$H(z)=\frac{Y(z)}{X(z)}=\frac{1}{1-2r\cos\omega_0\,z^{-1}+r^{2}z^{-2}}$$

对应的差分方程（把 $z^{-1}$ 理解为"延迟一个采样"）：

$$y[n]=x[n]+2r\cos\omega_0\,y[n-1]-r^{2}\,y[n-2]$$

**为什么叫"谐振器"**：它分母的根（极点）落在角度 $\pm\omega_0$ 上，于是频响在 $\omega_0$ 附近形成一个尖锐的峰。$r$ 越接近 1，峰越尖越高 —— 这正是本文要定量说明的事。

这类"只有极点、没有零点"的系统叫**全极点（all-pole）滤波器**，本文的 $b=[1]$ 就是这种情况。

### 踩坑：`a` 系数数组不需要反转

很多人以为传给 `tf2zpk()` 的 `a` 要**反过来写**。不用。同一串数有两种读法，且数值完全相同：

- 读作 $z^{-1}$ 的降幂系数 → 给 `freqz(b, a)` 用
- 读作 $z$ 的降幂系数 → 给 `tf2zpk(b, a)` 用

原因见第五节：$H(z)$ 上下同乘 $z^2$ 之后，分母恰好就是同一串数写成的 $z$ 的多项式。

## 二、复数的四个必备知识点

**① 复数的模**（勾股定理）
$$|a+bj|=\sqrt{a^{2}+b^{2}}\qquad\text{例：}|3+4j|=\sqrt{9+16}=5$$

**② 欧拉公式**（复数的极坐标写法）
$$e^{j\theta}=\cos\theta+j\sin\theta$$
取模得 $|e^{j\theta}|=\sqrt{\cos^{2}\theta+\sin^{2}\theta}=1$。

> 这是理解"单位圆"的钥匙：$e^{j\theta}$ 的模恒为 1，$\theta$ 从 0 走到 $2\pi$ 时正好画出一个半径 1 的圆。**单位圆 = 所有模等于 1 的复数**。

**③ 一元二次求根公式**
$$z^{2}+bz+c=0\;\Longrightarrow\;z=\frac{-b\pm\sqrt{b^{2}-4c}}{2}$$

**④ 乘法可以把模提出来**（后文两次用到）
$$|\alpha\beta|=|\alpha|\cdot|\beta|\qquad\text{特例：}|r\,e^{j\theta}|=r\cdot|e^{j\theta}|=r$$

## 三、极点是怎么解出来的

**第一步**：$H(z)$ 上下同乘 $z^{2}$，把负幂变成正幂（$z^{-1}\cdot z^{2}=z$，$z^{-2}\cdot z^{2}=1$）：

$$H(z)=\frac{z^{2}}{z^{2}-2r\cos\omega_0\,z+r^{2}}$$

**第二步**：极点是**分母等于 0 的根**：

$$z^{2}-2r\cos\omega_0\,z+r^{2}=0$$

对照求根公式，$b=-2r\cos\omega_0$、$c=r^{2}$：

$$z=\frac{2r\cos\omega_0\pm\sqrt{4r^{2}\cos^{2}\omega_0-4r^{2}}}{2}$$

**第三步**：根号里提出 $\sqrt{4r^{2}}=2r$，与外面的除以 2 抵消：

$$z=r\cos\omega_0\pm r\sqrt{\cos^{2}\omega_0-1}$$

**第四步**：用 $\cos^{2}\omega_0-1=-\sin^{2}\omega_0$，且 $\sqrt{-1}=j$：

$$z=r\cos\omega_0\pm r\sqrt{-\sin^{2}\omega_0}=r\cos\omega_0\pm j\,r\sin\omega_0$$

> 判别式为负 ⇒ 无实根 ⇒ **一对共轭复根**。这就是"极点总是成对出现"的来源。

**第五步**：提出公因子 $r$，套欧拉公式：

$$z=r\left(\cos\omega_0\pm j\sin\omega_0\right)=r\,e^{\pm j\omega_0}$$

**数值核对**（$r=0.9$、$\omega_0=\pi/4$）：$0.9\cos 45^\circ=0.9\times0.7071=0.6364$，极点即 $0.6364\pm0.6364j$ —— 与 `signal.tf2zpk()` 打印值一致。也可用 `np.roots(a)` 自证。

---

## 四、为什么 r 就是"离单位圆多远"

代入知识点①算模：

$$|r\,e^{\pm j\omega_0}|=r\cdot|e^{\pm j\omega_0}|=r\cdot 1=r$$

**极点到原点的距离就是 $r$**；而单位圆是"到原点距离 = 1"的圆。同一个方向上：

- 单位圆上的点：$1\cdot e^{j\omega_0}$
- 极点：$r\cdot e^{j\omega_0}$

两点距离：

$$|1\cdot e^{j\omega_0}-r\cdot e^{j\omega_0}|=|(1-r)e^{j\omega_0}|=(1-r)\cdot 1=1-r$$

| r | 极点到单位圆的空隙 $1-r$ |
|---|---|
| 0.50 | 0.5 |
| 0.80 | 0.2 |
| 0.90 | 0.1 |
| 0.95 | 0.05 |
| 0.99 | **0.01** |

所以"$r$ 决定离单位圆多远"不是约定，而是**算出来的**：$1-r$ 就是极点到圆的最近距离。画出零极点图后，可以直接拿尺子量那段空隙来验证。

## 五、为什么频响等于"距离之积的倒数"

把分母因式分解：

$$H(z)=\frac{z^{2}}{(z-p_1)(z-p_2)},\qquad p_1=r e^{j\omega_0},\;p_2=r e^{-j\omega_0}$$

取模，并让 $z$ 落在单位圆上（$z=e^{j\omega}$，代表频率 $\omega$）：

$$|H(e^{j\omega})|=\frac{|e^{j\omega}|^{2}}{|e^{j\omega}-p_1|\,\lvert e^{j\omega}-p_2\rvert}=\frac{1}{\lvert e^{j\omega}-p_1\rvert\,\lvert e^{j\omega}-p_2\rvert}$$

分子 $|e^{j\omega}|^{2}=1^{2}=1$，因此只剩分母。

**分母里每一项 $\lvert e^{j\omega}-p_i\rvert$ 就是"单位圆上的点 $e^{j\omega}$ 到第 $i$ 个极点的距离"。** 频率走到极点正下方时该距离最小 ⇒ 分母最小 ⇒ 幅频最大，起峰。

> $b=[1]$ 号称"没有零点"，分子怎么会有 $z^{2}$？因为在 $z$ 域里它对应**两个零点都在原点** $z=0$；而原点到单位圆上任何点的距离都是 1，对幅频毫无影响。这就是最终公式里只剩极点的原因。

## 六、峰高的定量预言

### 1. 取 $\omega=\omega_0$（极点正下方），分别算两个距离

**距离一**（近处极点）：
$$\lvert e^{j\omega_0}-re^{j\omega_0}\rvert=\lvert e^{j\omega_0}(1-r)\rvert=1\cdot(1-r)=1-r$$
关键一步：乘法提模（知识点④），且 $|e^{j\omega_0}|=1$。结果就是第四节那个空隙。

**距离二**（远处极点）：
$$\lvert e^{j\omega_0}-re^{-j\omega_0}\rvert=\lvert 1-r e^{-2j\omega_0}\rvert$$
展开 $e^{-2j\omega_0}=\cos 2\omega_0-j\sin 2\omega_0$，再算模：
$$\lvert 1-r e^{-2j\omega_0}\rvert=\sqrt{(1-r\cos 2\omega_0)^{2}+(r\sin 2\omega_0)^{2}}=\sqrt{1-2r\cos 2\omega_0+r^{2}}$$

本设计固定 $\omega_0=\pi/4$，于是 $2\omega_0=\pi/2$、$\cos 90^\circ=0$，该项干净地化简为 $\sqrt{1+r^{2}}$。

### 2. 合并（距离之积的倒数）

$$\boxed{\ \text{峰值}\ \approx\ \frac{1}{(1-r)\sqrt{1+r^{2}}}\ }$$

### 3. 数值表（$\omega_0=\pi/4$）

| r | 空隙 $1-r$ | $\sqrt{1+r^2}$ | 预测峰值 | dB |
|---|---|---|---|---|
| 0.50 | 0.5 | 1.118 | 1.79 | 5.0 |
| 0.80 | 0.2 | 1.281 | 3.90 | 11.8 |
| 0.90 | 0.1 | 1.345 | 7.43 | 17.4 |
| 0.95 | 0.05 | 1.379 | 14.50 | 23.2 |
| 0.99 | 0.01 | 1.407 | 71.07 | 37.0 |

趋势：**空隙 $1-r$ 每减半，峰值大约翻一倍。**

### 4. 近似与精确：一次自我更正

第一版推导里用过 $r\to1$ 的近似 $\sqrt{1+r^{2}}\to\sqrt{2}=1.414$，算出 1.8 / 3.5 / 7.4 / 14.1 / 70.7。上表用精确的 $\sqrt{1+r^{2}}$，$r$ 较小时差别可见（$r=0.8$：3.90 对 3.54）。

**更重要的是**：上表是**在 $\omega_0$ 这一点**取值，不是真正求最大值。$r$ 较小时实际峰值会略高、位置略偏向低频（$r=0.5$ 时约 1.8 出头，峰位略低于 $\pi/4$）；原因是分母里缓慢变化的第二项在低频方向偏大，把峰往那边拉了一点。$r\to1$ 时两者几乎完全吻合。

> **教训**：闭式近似与数值最大值本来就不总是同一个数。对比时看数量级和趋势，不要抠小数点。

## 七、稳定性判据与峰宽

**稳定性**：因果系统的极点必须**全在单位圆内**。

- $r<1$：极点全在圆内 ⇒ 稳定
- $r=1$：极点落在圆上 ⇒ 临界（等幅振荡）
- $r>1$：极点跑到圆外 ⇒ 不稳定，响应发散

所以第四节那个"空隙"不仅决定峰高，也决定系统离不稳定有多远。

**峰宽**（以下为 $r$ 接近 1 时的近似，**待程序验证**）：

$$\text{半功率带宽}\;\approx\;\frac{2(1-r)}{\sqrt{r}}\ \text{(rad/sample)}$$

即峰变高的同时也在**变窄**，两者是同一件事的两面。以 $f_s=8$ kHz 换算：$r=0.9$ 约 269 Hz，$r=0.95$ 约 131 Hz，$r=0.99$ 约 26 Hz。

## 八、整条逻辑链

```text
分母 = 0  →  极点 = r·e^(±jω0)  →  |极点| = r  →  到单位圆的空隙 = 1-r
                                                        ↓
              |H(e^(jω))| = 1 / (单位圆上点到各极点的距离之积)
                                                        ↓
                  距离最小(ω = ω0)处起峰 → 峰值 ≈ 1 / ((1-r)·√(1+r²))
                                                        ↓
                        r → 1  ⇒  空隙 → 0  ⇒  峰值 → ∞，同时峰宽 → 0
