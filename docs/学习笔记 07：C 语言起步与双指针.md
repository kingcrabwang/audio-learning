# 学习笔记 07：C 语言起步与双指针

对应代码：`dsp-toolbox/csrc/include/audio_block.h`、`csrc/src/audio_block.c`，以及三个数组练习。

## 数组、指针与结构体

`float samples[] = {0.8f, 0.4f, 0.2f};` 创建数组。函数接收 `float *samples` 时，通过地址访问调用方的数组，修改 `samples[i]` 会改变原来的元素。

```c
typedef struct {
    float *samples;
    int count;
} AudioBlock;
```

`AudioBlock` 把数组地址与元素数量放在一起。指针自身不保存数组长度，所以需要 `count`。

曾经出现的问题：修改全局数组，却打印 `main` 中的另一个同名或相近名称的数组。检查时应追踪“这个指针究竟指向哪份数据”，不能只看变量名。

结构体变量通过 `block.count` 访问成员；结构体指针通过 `s->nh` 访问成员。

## 头文件与 CMake

头文件声明类型和函数接口，源文件定义函数体。`#ifndef`、`#define`、`#endif` 组成头文件保护，避免同一编译单元重复包含声明。

`#include "audio_block.h"` 能否找到文件，取决于编译器的头文件搜索路径。当前项目由 CMake 的 `target_include_directories(... include)` 提供该路径。

CMake 生成构建配置；编译器才把 C 源码编译成程序。修改 `CMakeLists.txt` 后，需要重新运行配置步骤。只运行旧构建目录中的 CTest，不会自动注册新添加的测试。

```bash
cmake -S csrc -B /tmp/dsp-toolbox-build
cmake --build /tmp/dsp-toolbox-build
```

`-S` 指源码目录，`-B` 指构建目录。构建目录保存生成文件，源文件保留在仓库中。

## 三道双指针练习

| 题目 | 思考顺序 | 两个位置分别做什么 | 复杂度 |
|---|---|---|---|
| 移除元素 | 只需要维护保留元素的有效前缀 | `read` 检查每项，`write` 指向下一个保留位置 | 时间 O(N)，额外空间 O(1) |
| 反转字符数组 | 首尾交换，再向中间推进 | `left`、`right` 指向本轮交换的位置 | 时间 O(N)，额外空间 O(1) |
| 有序数组平方 | 最大平方一定在当前两端之一 | 两端比较，结果从右向左填 | 时间 O(N)，结果空间 O(N) |

移除元素返回的是有效长度，不要求删除数组尾部的旧值。反转字符数组在 `left < right` 时继续。平方排序在 `left <= right` 时继续，保留中间最后一个元素。

C 中声明 `void` 的函数不返回数组地址。若结果通过调用方提供的 `result` 数组写出，函数体结束即可；不要再写 `return result;`。

## 本轮后续遇到的内存语法

`malloc(字节数)` 申请未初始化的内存；`calloc(元素数, 单个元素字节数)` 申请并清零。`sizeof(float)` 计算元素占用的字节数，`sizeof(fir_state_t)` 计算状态结构体的大小。

申请失败返回 `NULL`。当前申请失败时，需要释放此前已经成功申请的内存。第一次申请结构体就失败时，还没有成功得到需要清理的内存。

`free(NULL)` 是允许的。结构体拥有两个数组时，先释放数组，再释放保存数组地址的结构体。
