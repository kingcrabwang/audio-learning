# 当前滤波器的限制与易错点

本页记录当前 FIR/IIR 与 C FIR 学习中已经遇到或需要明确的边界，不代表所有模块已经完成。

| 触发条件 | 可能出现的错误 | 当前处理或检查 |
|---|---|---|
| fc≤0、fc≥fs/2，或参数含 NaN/无穷大 | 无效设计或数值异常 | 设计函数先检查参数 |
| 把 bool 当整数阶数或长度 | True 被当成 1 | 类型检查显式拒绝布尔值 |
| 把复数极点转为 float64 | 丢失虚部，极点位置错误 | 中间极点和多项式使用 complex128 |
| 直接比较两种方法同一 fc 处幅度 | 把 −6 dB 与 −3 dB 的定义差异当成错误 | 说明 FIR 窗法与 Butterworth 的截止约定 |
| 阻带接近零时估计相位/群延迟 | 相位跳变、差分尖峰 | 相位与群延迟图先检查通带内部 |
| 把带通除以系数总和 | 按接近零的直流响应错误缩放 | 按第一通带中心响应归一化 |
| 把已归一化带通直接反演后要求 firwin 带阻系数 | 得到不同设计 | 使用未归一化加窗带通反演，再按直流归一化 |
| 把 FIR 陷波 q 当成精确 −3 dB 带宽规格 | 实际带宽与预期不一致 | q 只规定当前实现的名义设计宽度 |
| 低频、很窄的 FIR 陷波 | 自动长度大，延迟和乘加较多 | 选型时明确长度与延迟，勿据 q 单独承诺实时性 |
| 每块开始清零历史 | 块边界输出错误 | 以 1/7/64/512 点分块对拍 |
| 输出环形索引用输入缓冲区长度 | 不等长分子分母时出错 | 输入、输出索引各自绕回，并测试不等长情况 |
| IIR 的 a0 不为 1 | 输出缩放错误 | b、a 同时除以原来的 a0；a0=0 拒绝 |
| 块里出现非法样本 | 处理半块后状态被破坏 | Python 在处理循环前整体检查输入 |
| C 用 k 当系数，或把 n 当 nh | 错误乘加或越界 | k 是系数下标，使用 h[k]；n 是块长，nh 是系数数量 |
| C 直接使用负数余数当下标 | 负索引访问数组外部 | 负的 write_index−k 加 nh 后访问 |
| malloc 返回地址写入 nh | 地址与整数混淆 | 地址写入 h，数量写入 nh |
| 后续分配失败而遗漏前面的分配 | 内存泄漏 | 数组和状态依次清理；free(NULL) 允许 |
| 修改 CMake 后未保存或未重新配置 | CTest 找不到注册测试 | 保存后重新配置、编译，使用 ctest -N 检查 |

当前 IIR 仅实现 Butterworth 低通，使用多项式系数与直接型递推。已测用例包含 1、2、4、6 阶；尚未证明任意高阶、极端截止频率的数值表现，也未实现二阶节结构。

C 测试覆盖指定的数值与状态行为，没有替代内存泄漏检测和实际平台性能测试。真实录音实验、等波纹设计与计划中的其他设计方法仍需后续验收。
