# 当前滤波器公式速查

本页覆盖已经学习并实现的滤波器部分；其他模块公式后续按学习进度补充。

| 内容 | 公式或约定 |
|---|---|
| 数字角频率 | ω=2πf/fs，单位 rad/样本 |
| FIR 设计归一化频率 | c=2fc/fs，奈奎斯特频率对应 1 |
| FIR 卷积 | y[n]=Σ h[k]x[n−k] |
| 频率响应 | H(f)=Σ h[k]exp(−j2πfk/fs) |
| 对称 FIR 群延迟 | D=(N−1)/2 个样本，τ=D/fs 秒 |
| 幅度增益转 dB | 20log10(abs(H)) |
| 群延迟，横轴用 Hz | τg=−(dφ/df)/(2π)，单位秒 |
| 一般 IIR | a0*y[n]=Σ b[k]x[n−k]−Σ(k≥1) a[k]y[n−k] |
| 双线性替换 | s=2fs(1−z⁻¹)/(1+z⁻¹) |
| 截止频率预畸变 | Ωc=2fs*tan(πfc/fs)，单位 rad/s |
| 模拟极点转数字极点 | pd=(2fs+p)/(2fs−p) |
| Butterworth 模拟极点角度 | θk=(2k+N+1)π/(2N)，k=0…N−1 |
| Butterworth 数字低通零点 | z=−1，共 N 个，分子含 (1+z⁻¹)^N |
| 直流增益 | H(1)=sum(b)/sum(a) |
| FIR 带通 | 理想高截止低通减低截止低通，再加窗并按通带中心缩放 |
| FIR 带阻谱反演 | δ[n−D] 减未归一化的加窗带通，最后按直流缩放 |

稳定性结论需要结合因果性与 ROC：当前因果模拟滤波器极点在左半平面；当前因果数字 IIR 极点在单位圆内。任意有理式仅看极点而不说明 ROC，不能覆盖所有双边序列情况。

注意：相位斜率不直接等于秒数；图的 dB 是幅度比，不是功率比；实际滤波器的截止频率不是“立即从 1 变成 0”的开关。
